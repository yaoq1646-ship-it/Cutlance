## 它能干什么（均为已实测功能）

**多路输入，接得住各种信号源**

- 本地文件 / 摄像头 / 桌面捕获
- 采集卡（HDMI 内嵌音频，最多 8 路音频通道）
- 网络流：**RTSP / SRT / RTMP / HLS(HTTP) / RIST / UDP**，支持一次粘多条批量添加、协议自动识别、连接预检
- **NDI** 局域网输入与输出（广播节目画面给其它 NDI 软件）

**专业切换台**

- PREVIEW / PROGRAM 双总线监视器，CUT / Fade / AlphaFade 三种转场（AlphaFade 即交叉溶解）
- 固定 **8 通道叠加图层**（文字 / 图片 / 字幕 / 表格 / PPT），实时合成到节目画面

**字幕与表格（Excel 一键上屏）**

- **字幕表**：一张 Excel 表 = 几十上百条字幕，翻页即上屏；字号 / 位置 / 颜色可调；上屏前可对照前后条内容，**防串行、防漏行**
- **表格进预览**：按 Excel 打印分页翻页上屏，适合直播里看报表

**PPT 直进直播（省事的一条）**

- 两种方式互补：纯静态页走图片序列；**有动画 / 转场 / 内嵌视频 / 声音时，直接抓取 PowerPoint 放映窗口**——动画由 PowerPoint 自己驱动，直播里观众看到的是流畅的演示而非"跳页"
- 注：vMix 原版的 PowerPoint 输入只导出静态页，要带动画得另开一台机走桌面采集；Cutlance 单机直抓放映窗，这一项更省事

**音频与画面**

- **8 路音频混音**（分通道音量 / 静音）
- 色键抠像换背景（纯色 / 图片 / 视频三种背景）
- 画面美体形变、裁切 / 旋转 / 镜像
- 横屏 / **竖屏输出**、HDMI 全屏镜像多显示器、NDI 局域网广播

**现场稳定相关的细节**

- **倒计时触发器**：可倒计时到"计算机的某个时刻"（如 21:00），到点弹最上层提醒框，带**一键开始推流 / 录制**按钮
- **50 个导播动作**可绑定任意快捷键（支持外设导播键盘 / 小键盘），全局生效，带冲突检测
- **断流自动重连**（退避 1/2/4/8/15/30 秒）、输入信号**四态状态灯**（正常 / 重连中 / 无信号 / 直连）
- 关闭程序自动保存工程，不丢工作
- 布局文件 **.vpreset** 可保存、可分享，一次调好处处复用
- 多分辨率 / 缩放自适应，小屏也不裁按钮

## 快速上手

1. 打开软件，左侧点 **+ 文件 / + 摄像头 / + 桌面 / + 采集卡 / + 网络流** 把信号加进来；
2. 单击某路输入 → 它出现在 **PREVIEW（蓝框）**；再点另一路切换预览；
3. 点 **CUT** 硬切，或选 **Fade / AlphaFade** 后点 **AUTO** 做转场 → 画面进入 **PROGRAM（红框）** 即对外输出；
4. 需要字幕：右侧叠加层栏点 **+ 字幕表** 选 Excel → 翻页即上屏；
5. 需要 PPT：点 **+ PPT** 选文件 → 选"视频采集"方式 → 放映窗被抓取进直播；
6. 推流 / 录制：打开输出设置，配置 RTMP 地址与分辨率后点"开始推流 / 录制"。

更细的操作见软件内「帮助 → 快捷键说明」。

## 想看代码 / 自行编译（面向开发者）

Cutlance 基于 **C# / WPF / LibVLC（LibVLCSharp）** 构建。

环境要求：

- Windows 10 / 11
- .NET 8 SDK（<https://dotnet.microsoft.com/download）>

本机编译与运行：

```bat
cd Cutlance\Cutlance
dotnet restore
dotnet build
start "" bin\Debug\net8.0-windows\Cutlance.exe
```

> 项目内层 `Cutlance\Cutlance\build_run.bat` 可一键编译并启动，避免跑了旧 exe。
