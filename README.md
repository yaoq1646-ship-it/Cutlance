# Cutlance v1.0 发布说明

## 🎬 这是什么

**Cutlance** 是一款 Windows 平台的轻量级直播导播 / 切换台软件。

它的特别之处在于——作者是一个直播行业的从业者、一个**编程小白**，全程在 **WorkBuddy** 协助下一步步把它造了出来。一个外行，也能做出专业级工具；一个"程序员"和"小白"之间的巨大沟壑，被 WorkBuddy 铺垫成了宽阔的道路。

**最重要的是：它永久免费，不收任何费用。**

## ✨ 本次发布包含（1.0）

编译好的可运行程序，自包含、双击即用，无需安装、无需额外安装 .NET 运行库。已实测功能包括：

- **多路输入**：文件 / 摄像头 / 桌面 + 采集卡 + 网络流（RTSP / SRT / RTMP / HLS / RIST / UDP）+ NDI 局域网收发
- **专业切换台**：PREVIEW / PROGRAM 双总线、CUT / Fade / AlphaFade 转场、8 通道叠加图层
- **Excel 字幕表**：一张表 = 几十上百条字幕，翻页上屏，样式可调，上屏前可对照前后条内容防串行
- **Excel 表格进预览**：按打印分页翻页上屏
- **PPT 直进直播**：抓 PowerPoint 放映窗，带动画 / 转场 / 内嵌视频 / 声音（比 vMix 原版只导静态页更省事）
- **8 路音频混音**、色键抠像换背景、美体形变、横 / 竖屏输出
- **倒计时触发器**：到指定时刻弹框提醒 + 一键开播
- **50 个导播动作**绑任意快捷键（支持外设导播键盘，全局生效）
- **稳定性细节**：断流自动重连、输入信号四态状态灯、关闭自动保存工程、布局文件 .vpreset 可分享

## 💡 使用小提示

- 首次使用建议先看软件内「帮助 → 快捷键说明」；
- 字幕、PPT 推荐用"视频采集 / 字幕表"方式，上屏前可在样式窗对照内容防串行；
- 推流前确认输出设置里的 RTMP 地址正确；工程文件（`.cutlance`）含推流密钥，外发注意脱敏。
